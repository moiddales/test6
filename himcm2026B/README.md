# 2026 HiMCM Problem B：开放空间冷却的能量浪费

## 统一定义

> 冷却效率 = 送达目标的有用冷却服务 ÷ 投入的全部资源，系统边界须事先说明。

- 冷柜：η_F =（可取货陈列面积 × 营业小时 × [商品 ≤ −18°C]）÷（冷柜用电 + 商场空调净变化），单位 m²·h/kWh。
- 公交站：η =（受益人数 × 按热应激等级加权的 UTCI 缓解量）÷ 电功率，单位 人·°C·h/kWh。

## 已有的主要结论

1. **敞口冷柜 87% 的冷量耗在开口上。** 同一台冷柜在潮湿商场里多耗 50% 的电；加门省 58%；卧式冷柜每平方英尺的 DOE 能效限值只有立式的 1/4。
2. **公交站上哪台设备效率最高由气候决定。**
   - 湿热天风扇最好，效率是蒸发冷却的 4–10 倍。
   - 干热天（≥ 36°C 且空气足够干）风扇会让人更热，应改用蒸发冷却：候车 ≤ 6 人用 B，≥ 8 人用 C。
3. **只有大型蒸发冷却器 C** 能在 43°C 的干热高峰时段把乘客拉出"非常强热应激"。这是第 4 问"效率与效果"权衡的起点。
