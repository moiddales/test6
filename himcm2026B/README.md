## 当前模型边界

- 额定效果以候车位置为主口径，出口上限为独立敏感性情景；设备数量增加覆盖，不累加每人的额定降温。
- UTCI 超适用范围或额定包络无法实现时，全天效率不排名。物理诊断数据仍保留，并有原因标记。
- 风扇/蒸发设备的持续与按需策略显式比较；蒸发设备停机后耗电耗水归零，区域热湿状态继续演化。
- 指标是加权人时缓解量除以运行资源，另报水耗、残余类别暴露和成本。覆盖/混合指数不是能量分配。
- 真实天气按日检验；两个真实场所采用明示的研究区域和设备假设。现场局部气象、人数、设备性能及成本均未实测。

## 复现

在本目录：

```bash
python -m pip install -r requirements.txt
python tools/reproduce.py
```

只检查已有输出：`python tools/reproduce.py --verify-only`。默认完整复现包含 3,000 组参数采样，耗时随机器变化。当前远端复现入口仅生成模型结果和关键数字，不生成暂缓发布的报告。数值检查、证据比较和现场准确性是不同层次，不能互相替代。

提交前仍需团队填写控制编号、复核 AI 披露并承担最终方案责任。定价参数是情景输入，不是采购报价。
