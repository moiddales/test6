# 2026 HiMCM Problem B：开放空间冷却的能量浪费

## 统一定义

> 冷却效率 = 送达目标的有用冷却服务 ÷ 投入的全部资源，系统边界须事先说明。

- 冷柜：η_F =（可取货陈列面积 × 营业小时 × [商品 ≤ −18°C]）÷（冷柜用电 + 商场空调净变化），单位 m²·h/kWh。
- 公交站和车站：η =（受益人数 × 按热应激等级加权的 UTCI 缓解量）÷（用电 + 用水的隐含能耗 0.53 kWh/m³），单位 人·°C·h/kWh。

## 主要结论

1. **冷柜：** 88% 的制冷负荷由开口造成。同一台冷柜在潮湿商场里多耗 56% 的电；加门省 55%；DOE 现行能效限值中卧式冷柜每平方英尺只有立式的 1/4。
2. **公交站**（设计日用凤凰城、休斯敦机场 2020–2024 年 7 月最热 10% 日子的实测曲线）：
   - 湿热天风扇效率最高，是蒸发冷却的约 4–8 倍。但 35°C 以上风扇是否有益文献有分歧，最热的几个小时、尤其对老年人，还要靠蒸发冷却或避暑点。
   - 干热天风扇在凤凰城高温日 13–20 时有害，要用蒸发冷却：人少时 B 略好，人多时用 C。
   - 蒸发冷却器的冷量只有 20–26% 吹到人身上。
   - 遮阳顶棚不耗电：干热天的缓解接近整天开 B，湿热天约为风扇的 86%。
   - 侧挡风板只适合干热地区；湿热地区挡风反而让所有人更热。
   - 46°C 高峰时没有一台设备能让候车乘客脱离"非常强热应激"。
3. **车站：**
   - 开放度决定哪种设备效率最高：湿热天开放度高于约 10% 时是风扇；干热天开放站台是 C，封闭车站是 B。
   - 但封闭车站（屏蔽门站台、封闭候车室）里蒸发冷却会让湿度超过 ASHRAE 62.1 规定的 65%，所以那里只能用空调。
   - 封闭但不开冷却的车站比室外热 1.2–7.0°C，屋顶受晒是主要原因之一。
   - 开放度 ≥ 76% 时，公交站模型对蒸发冷却效率的误差在 11% 以内。
