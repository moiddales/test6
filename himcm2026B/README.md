# 2026 HiMCM Problem B：开放空间冷却的能量浪费

## 统一定义

> 冷却效率 = 送达目标的有用冷却服务 ÷ 投入的全部资源，系统边界须事先说明。

- 冷柜：η_F =（可取货陈列面积 × 营业小时 × [商品 ≤ −18°C]）÷（冷柜用电 + 商场空调净变化），单位 m²·h/kWh。
- 公交站和车站：η =（受益人数 × 按热应激等级加权的 UTCI 缓解量）÷（用电 + 用水的隐含能耗），单位 人·°C·h/kWh。

## 主要结论

1. **冷柜：** 87% 的冷量耗在开口上。同一台冷柜在潮湿商场里多耗 50% 的电；加门省 58%；卧式冷柜每平方英尺的 DOE 能效限值只有立式的 1/4。
2. **公交站：**
   - 湿热天风扇最好，效率是蒸发冷却的 4–10 倍。
   - 干热天（≥ 36°C 且空气足够干）风扇反而让人更热：候车 ≤ 6 人用 B，≥ 8 人用 C。
   - 蒸发冷却器的冷量只有 24–34% 吹到人身上。
   - 遮阳顶棚一天带来的缓解比 B 还多，而且不耗电。
3. **车站：**
   - 开放度决定该用哪种设备：湿热天开放度高于约 8% 时风扇最好，封闭候车室里空调最好；干热天始终是 B，但在封闭空间里它会把湿度推到 65% 以上。
   - 封闭但不开冷却的车站比室外热 1.8–7.2°C。
   - 开放度 ≥ 50% 时，公交站模型对蒸发冷却效率的误差在 11% 以内；越封闭越必须用修订后的车站模型。
