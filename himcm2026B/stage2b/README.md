# 2b 车站模型

入口 `run_2b.py`，热湿状态与控制实现见 `station.py`。当前数值见 outputs/ 与 ../paper/key_results.md；完整报告及英文节选暂缓发布，等待用户批准。

- 热增益、蓄热、乘客潜热、风/浮力交换、列车脉冲、蒸发湿量和空调共同进入动态平衡。
- 默认持续运行，按需策略显式标记。湿度控制使用所选 60/65% 滞回与一步预测；65% 是管理情景，适用性及例外见 ASHRAE 来源，不是普遍安全阈值。
- 停机时供气、设备热、耗电耗水停止，但区域温湿度继续演化。相同场景的系统比较保持相同客流、时段和无设备基线。
- `full_day_supported` 同时要求 UTCI 有效与额定包络可实现；`utci_supported`、`rating_supported`、越界小时和诊断暴露说明原因。某些封闭场景仅室外通风也能产生超过额定值的总温差，旁通无法实现约束：这些场景不进入主排名。
- 空调 `supply_share` 为显式参数，不以送风口高度自动证明 100% 有效。
- `table2b_8_shelter_bridge.csv` 调用真实 2a/2b 引擎并对齐输入。`table2b_1_ablation.csv` 与图 11 是车站模型内部消融，不是 2a 模型误差。不存在从这项消融得到的通用开口率阈值。

运行 `python stage2b/run_2b.py`。四项数值/基准检查不是四项独立现场验证；详细未验证输入见 `../analysis/UNCERTAINTY.md`。所有历史固定数字已由当前输出和完整报告替代。
