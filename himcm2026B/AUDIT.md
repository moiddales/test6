## 1. A 级：会改变结论

### A1 候车亭下的平均辐射温度设得太低（2a）

**现状：** 阴影下的平均辐射温度（MRT）取气温 + 4°C（`dR_shade = 4`），日晒下取气温 + 30°C。

**文献：**

- **Middel & Krayenhoff 2019**（坦佩实测）：气温 48.5°C 时 MRT 最高 76.4°C。日晒比气温高约 28°C，支持我们的 +30。
- **Middel 等 2021 "50 Grades of Shade"**（坦佩实测，摘要）：
  - 不同遮阳类型之间，辐射温度降幅相差可达 50°C；
  - **轻质遮阳结构的效果排在建筑阴影和树荫之后**，候车亭就属于这一类。
- **亚利桑那大学图森 MaRTy 报告**（只看到检索摘要，原文 403）：候车亭平均让 MRT 比全日晒低约 15°C；建筑阴影低约 23°C。

**推算：** 候车亭下的 MRT ≈ 气温 + 28 − 15 ≈ 气温 + 13°C，而不是 + 4°C。

**影响**（探针重跑设计日，智能控制）：

| `dR_shade` | 干热 η：A / B / C | 湿热 η：A / B / C | 遮阳缓解（干 / 湿，人·°C·h/天） | 湿热天 B 运行后剩余"非常强热应激"（人·小时） |
|---|---|---|---|---|
| 4（现值） | 28.3 / 33.5 / 29.4 | 55.5 / 14.7 / 11.6 | 896 / 404 | 0 |
| 9 | 30.1 / 35.9 / 31.3 | 65.9 / 16.3 / 12.4 | 738 / 285 | 0 |
| 13（文献推算） | 31.3 / 38.1 / 32.8 | 72.7 / 18.3 / 13.8 | 603 / 181 | 20.3 |

**被推翻的原话：**

- `stage2/README.md` 第 48 行和 `section_2a_draft.md` 第 159 行写道："遮阳……干热天 896，超过 B（655）……湿热天 404，与 C（406）相当"。
- 取 +13°C 后，湿热天的遮阳缓解只有 C 的 45%；干热天也低于 B，因为 B 的缓解随辐射温度升高只增不减，在 +4°C 时就已经是 655。
- 另外，"湿热天 B、C 都能把非常强热应激降到 0"在 +13°C 时对 B 不成立。

**不受影响：** 设备排名。

**修改建议：**

1. 基准值改为 12°C，敏感性范围 8–16°C（现在的 0–10 不包含文献值）。
2. 重跑后重写遮阳那几句。遮阳仍然是零能耗的第一选择，但不要写"比 B 强"。

**代价：** 小。

### A2 挡风板的"效率提高 7–21%"用了两个不同的基准（2a）

**现状：** `design_levers()` 拿"有挡风板 + 设备"与"有挡风板、无设备"比较，再与"无挡风板"情况下的设备效率并列。但挡风板本身就改变了所有候车人的体感，而且干热天和湿热天的方向相反：

| | 只加挡风板、不开设备（人·°C·h/天） |
|---|---|
| 干热天 | **+71.2**（挡住 46°C 的热风，体感变好） |
| 湿热天 | **−64.6**（挡住了能帮助出汗散热的风，体感变差） |

**在同一个基准下比较**（以"无挡风板、无设备"为基准），湿热天加风扇的情况：

- 有挡风板：总缓解 = −64.6 + 246.3 = 181.7 人·°C·h/天；
- 无挡风板：只开风扇是 190.3。

所以**在湿热天，挡风板总体是负作用**。

**被推翻的原话：**

- `stage2/README.md` 第 49 行和 `section_2a_draft.md` 第 160 行："挡风板让各设备效率提高 7–21%"。

**修改建议：**

1. 用统一基准重算；
2. 结论改为"挡风板只适合干热地区；湿热地区候车亭要保持通风"。这本身是一条有价值的、因气候而异的建议，可以放进第 5 问的指南。

**代价：** 小。

### A3 风扇在 35°C 以上是否有益，文献有分歧（2a，影响第 4–5 问）

**现状：**

- 模型用 UTCI 评价风扇；
- 检验依据是 Morris 2019 和 Ravanelli 2015 的静坐实验（风扇在 40°C、湿度 50%，以及 42°C、湿度 50% 时有益）；
- 湿热天"风扇效率最高"是 2a 的主要结论之一。

**新查到的文献：**

| 文献 | 结论 | 与我们模型的关系 |
|---|---|---|
| Bröde & Kampmann 2023，*Biology* 12:802（摘要） | 5 名受试者在跑步机上行走，共 198 次实验。超过 35°C 时，水汽压高于 2 kPa（心率、核心体温）或 3 kPa（皮温、出汗）风才有益；**UTCI 对风的效果预测与实测相关系数 r = 0.9** | 支持用 UTCI 评价风扇。我们模型的有益边界在 40°C 时是 1.05 kPa、44°C 时是 2.63 kPa，比这项运动实验更偏向"风扇有益" |
| Morris 等 2021，*Lancet Planet Health*（摘要） | 生物物理模型：任何湿度下，风扇都不会变得有害的温度上限是年轻人 39°C、老年人 38°C、服抗胆碱药的老年人 37°C | 基本一致：我们模型在 38°C 时只有湿度 < 6.5% 才有害，39°C 时 < 10.6% 才有害 |
| Meade 等 2024，*Lancet Planet Health*（摘要） | 批评性综述：35°C 以上风扇虽然促进出汗蒸发，但**对核心体温没有有意义的降低**；建议卫生机构继续反对 35°C 以上使用风扇，老年人尤其如此 | 与我们的湿热天结论直接冲突 |

**影响：** 按 Meade 的观点做探针，把 35°C 以上的风扇缓解截为 0：

- 湿热天风扇的 η 仍然最高（56.2），但**一天只有 8 个小时开**，最热的时段没有覆盖；
- 那几个小时需要蒸发冷却或避暑点来补。

**修改建议：**

1. 论文里明确写出这个分歧，以及我们的模型站在哪一边；
2. 加一行检验表，把我们的风扇有益边界和三篇文献的阈值并列；
3. 第 4 问"有效性"里把风扇的作用限定为"35°C 以下或湿热时段的主力；35°C 以上不能单独依靠，尤其是老年人"。

**代价：** 中（主要是写作）。

### A4 设计日上人数取了平均值再截断，系统性高估小容量设备（2a）

**现状：** 受益人数 = min(平均候车人数, 设备覆盖人数)。但候车人数是随机的（泊松分布），而 E[min(N, cap)] < min(E[N], cap)。

**影响**（设计日累计的"被覆盖人·小时"）：

| 设备 | 覆盖人数 | 高估比例 |
|---|---|---|
| A 风扇 | 4 | 15%（实际是 0.869 倍） |
| B | 6.25 | 10%（0.912 倍） |
| C | 9.4 | 1%（0.988 倍） |

- 干热设计日的 B 对 C 原来是 33.5 对 29.4。按比例近似修正后约为 **30.6 对 29.0**，B 仍然略好，但差距从 14% 缩到约 5%。
- 结论"人少用 B、人多用 C"不变，但"B 明显更好"要改成"两者接近"。

**修改建议：** 用泊松期望 E[min(N, cap)] 代替。这只需要改一行代码，候车亭和车站都适用。

**代价：** 小。

### 执行中与计划不同的地方

1. **除霜热不计入标定基准。** 我先试过把除霜热也算进"渗入占 75%"的分母。结果渗入流量增加 64%，敞口柜超出 DOE 限值，两项加门检验也失败了。SCE 的 70–80% 描述的是两次除霜之间的稳定负荷，所以标定保持原来的口径，除霜热只作为额外负荷加入。
