# 冷柜：效率定义的物理动机

本节用于解释系统边界和有效服务，不再作为已校准的低温冷柜预测工具。

`freezer.py` 保留一个明确标为示例的热负荷账本：渗透显热/潜热、辐射、传导、内部设备和除霜，再加压缩机及辅助用电。75% 渗透占比是情景假设；SCE 2004 的中温陈列柜证据不能直接校准本例 -25°C 的冷柜。其能源标准比较也不是准确性验证。

服务量应考虑食品温度合格、有效展示量、可达性和营业时间。`service_m2h_per_case_kwh` 只除以柜体用电；`service_m2h_per_system_kwh` 还包括显式设定的门店 HVAC 增量。代码没有食品温度模型，合格服务量仅是假定，不能据此作食品安全判断。

运行 `python stage1/freezer.py`。输出中的三项检查是数值记账恒等式；外部资料的适配程度另在 `tableS0_evidence_status.csv` 记录。门改造的售价/毛利“盈亏平衡点”已撤回；示例毛节电收益不包括投资、维护、门店 HVAC 和销售影响。

正文只保留物理解释、效率边界和证据局限。详细示例表保留供复算，不作现场效益承诺。
