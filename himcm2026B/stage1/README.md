# 阶段一：敞口冷柜的冷却效率该包含什么（Requirement 1）

## 1. 结论

**效率不能只看能耗。** 冷柜的冷却效率应定义为"有用服务 ÷ 全部资源投入"：

> η_F = 可取货的陈列面积 × 营业小时数 × [商品 ≤ −18°C] × 取货便利系数 ÷（冷柜用电 + 冷柜给商场空调带来的净电耗变化）

单位是"m²·h / kWh"。其中 [商品 ≤ −18°C] 是硬约束：做不到，服务记为 0。

下面七个量都应进入这个指标，括号里是本模型算出的影响幅度：

| # | 量 | 为什么必须计入 | 影响幅度（12 ft 低温立式敞口冷柜） |
|---|---|---|---|
| 1 | **商品温度**（食品安全，≤ −18°C） | 这是冷柜存在的目的。只看能耗时，拔掉电源"最节能" | 硬约束 |
| 2 | **冷量去向**：有多少冷量用在商品上，多少从开口漏掉 | 敞口冷柜 87% 的制冷负荷从开口进来（渗入 75%，辐射 12%），只有 13% 用于抵消柜体传热和内部发热 | 87% |
| 3 | **能耗构成**：压缩机、风机照明加热器、除霜 | 渗入空气带进的水汽结成霜，除霜每天还要再耗 19.7 kWh | 119 kWh/天，其中除霜 17% |
| 4 | **环境条件**：商场温度和湿度 | 冷柜和商品完全相同，商场从 21°C / 40% 变成 27°C / 70%，用电就 ×1.50 | ×1.50 |
| 5 | **设计**：风幕、夜间盖帘、玻璃门、立式或卧式 | 夜帘省 22%；玻璃门省 58%；DOE 能效限值中卧式敞口每平方英尺的限值只有立式的 1/4 | −22% / −58% / ×1/4 |
| 6 | **系统边界**：冷柜与商场空调的相互作用 | 漏出的冷量在制冷季替商场空调干了活，在采暖季则加重供暖 | 制冷季全店净电耗 −27%，采暖季 +7% |
| 7 | **顾客取货便利**（与销售额挂钩） | 加门省电，但要满足"门不影响销售"这个前提 | 盈亏平衡点：毛利损失 8.95 美元/天 |

**由此推出的三条原则**（阶段二直接沿用）：

1. **只算送达目标的冷量。** 冷柜的目标是商品，公交站的目标是乘客。
2. **设备效果随环境变化。** 商场湿度决定冷柜负荷，室外湿球温度决定蒸发冷却效果。
3. **效率的分子是服务，分母是全部资源，并要先划清系统边界。**

## 2. 冷柜与开放式公共空间的对应关系

| 冷柜 | 公交站 / 火车站 | 在阶段二模型中的对应 |
|---|---|---|
| 商品（要保持低温的对象） | 候车乘客 | 效率分子只计入受益人数 N_ben |
| 商品温度 ≤ −18°C（食品安全） | UTCI 热应激等级（人身安全） | 按热应激等级加权的缓解量 R |
| 开口（顾客要取货） | 敞开的侧面（乘客要上下车） | 开口必须保留，只能减少它带来的损失 |
| 风幕 | 挡风板、定点送风射流 | 定点模式公式 θ |
| 渗入：冷空气从底部流出，暖湿空气流入 | 冷空气从侧面底部溢出，风把冷量吹走 | 浮力溢出 Q_buoy 与风压换气 Q_wind |
| 渗入的水汽结霜，需要除霜 | 蒸发冷却向空气加湿 | 体感指标计入湿度；耗水量单独报告 |
| 商场温湿度 | 室外气温、湿度、风速 | 气候决定排名（阶段二图 3） |
| 夜间盖帘（闭店时） | 无人候车时关机 | 智能控制（阶段二表 2） |
| 漏出的冷量部分被商场回收 | 漏出的冷量全部散失到街道 | 开放场所无法回收，所以输送效率更关键 |
| 卧式冷柜：冷空气沉在柜底不外流 | 下沉式或三面围合的候车区 | 第 3 问可推广的设计特征 |

## 3. 模型

参考对象：12 ft（3.66 m）低温立式敞口多层冷柜，带风幕，远置式冷凝。开口 3.66 × 1.6 m（TDA 63 ft²），柜内空气 −25°C，商品表面 −20°C。商场取 25°C / 60%（常被引用为 ISO 23953 气候等级 3，但标准里的等级表未能核实；第 4 节对商场温湿度做了敏感性分析）。

**制冷负荷** = 渗入（显热 + 潜热）+ 开口辐射 + 柜体传导 + 内部发热

- **渗入：**
  - 质量流量 ṁ 按文献比例标定：SCE 实测中温敞口立式柜的渗入占总冷负荷 70–80%（ACEEE 2004，其测试值 73%），本模型取 75%。标定结果 ṁ = 0.053 kg/s，相当于商场空气以 0.8 cm/s 的速度穿过整个开口。
  - 显热：ṁ × 1.006 × (T_store − T_case)。
  - 潜热：ṁ × (W_store − W_case) × (2501 + 1.86T + 334)。水汽在柜内先凝结再结霜，所以凝结热和凝固热都要计入。
- **辐射：** ε·F·σ·A·(T_store⁴ − T_product⁴)，有效发射率乘角系数 ε·F = 0.56。
- **传导：** U·A·ΔT，柜体 U = 0.45 W/m²K、A = 16.4 m²；玻璃门 U = 1.5 W/m²K。
- **内部发热：** 风机 0.20 kW + 照明 0.15 kW + 防凝露加热器功率的 50%。
- **用电：**
  - 总用电 = 制冷负荷 / COP + 风机 + 照明 + 加热器 + 除霜，低温系统 COP = 1.6。
  - 除霜用电 = 结霜量 × 融霜所需热量 ÷ 除霜效率 0.3。
- **玻璃门：**
  - 没有开口辐射，只剩玻璃传导。
  - 渗入只发生在开门时：每次开门换掉 0.35 m³ 柜内冷空气。
  - 门店场景：每扇门每小时开 20 次，营业 16 小时。
  - 检验场景：用 ASHRAE 72 的测试程序，每扇门每小时开 6 次，共 8 小时。
- **夜间盖帘：** 闭店 8 小时，盖帘挡住 80% 的开口负荷。
- **商场空调：**
  - 冷柜从商场空气中带走的热量 = 渗入 + 辐射 + 传导。
  - 制冷季：这部分热量替空调干了活，按空调 COP 3.0 折算为省下的电。
  - 采暖季：要用热泵（COP 2.5）把显热部分补回来。
  - 制冷季占比：类休斯敦 0.85，类明尼阿波利斯 0.35。

## 4. 结果

### 表 S1：三种设计（商场 25°C / 60%）

| 设计 | 制冷负荷 kWh/天 | 从开口进入的比例 | 结霜 kg/天 | 用电 kWh/天 | 服务效率 m²·h/kWh |
|---|---|---|---|---|---|
| 敞口 + 风幕 | 141.6 | 87% | 52.3 | 119.0 | 0.79 |
| + 夜间盖帘 | 108.7 | 83% | 38.3 | 93.2 | 1.01 |
| 玻璃门（门店客流） | 49.8 | 37% | 9.1 | 50.1 | 1.87 |

敞口冷柜的负荷构成（图 S1）：渗入显热 64.3、渗入潜热 41.8、辐射 16.9、传导 8.9、内部发热 9.6 kWh/天。

### 表 S2：商场环境（图 S2）

同一台敞口冷柜：

- 商场 21°C / 40%：91.1 kWh/天
- 商场 27°C / 70%：136.8 kWh/天（×1.50）

相对湿度每升高 10 个百分点，用电增加 6–9 kWh/天。

### 表 S3：系统边界

| 商场类型 | 设计 | 冷柜用电 | 商场空调变化 | 全店净用电 |
|---|---|---|---|---|
| 制冷为主（类休斯敦） | 敞口 | 119.0 | −32.0 | 87.0 |
| | 玻璃门 | 50.1 | −8.9 | 41.3 |
| 采暖为主（类明尼阿波利斯） | 敞口 | 119.0 | +8.0 | 127.0 |
| | 玻璃门 | 50.1 | +3.5 | 53.7 |

在制冷为主的商场里，敞口冷柜真实的能源代价比只看冷柜电表低 27%。不过在两种商场里，加门都仍然是净节能。

### 取货便利的代价

每台冷柜加门每天省电 69 kWh，按 0.13 美元/kWh 计，每年省 3,268 美元。只要加门造成的毛利损失低于每天 8.95 美元（相当于每天少卖约 9 件毛利 1 美元的商品），加门就划算。新西兰门店试点在加门后没有观察到持续的销售下降。

### 敏感性（表 S4）

- 渗入比例在文献范围 70–80% 内变化：敞口冷柜用电 100–148 kWh/天（80% 时略超 DOE 限值 145.5），加门后制冷负荷降 58–72%（门店客流）。
- 每扇门每小时开门 6 / 20 / 40 次：加门后制冷负荷分别降 74% / 65% / 52%。门店开门越频繁，加门的节能效果越小。

### 检验（表 S0，4 项全部通过）

| 检验 | 模型 | 参照 |
|---|---|---|
| 加门后的制冷负荷降幅（ASHRAE 72 开门程序） | 75.9% | SCE 实验室 68%；Hillphoenix 80%（ASHRAE 72） |
| 加门后的用电降幅（同一程序） | 68.5% | Hillphoenix 71%（ASHRAE 72） |
| 敞口冷柜用电 vs DOE 现行限值（VOP.RC.L = 2.2·TDA + 6.85，2017 年起） | 119.0 kWh/天 | 限值 145.5 kWh/天 |
| 潜热负荷 = 结霜量 ×（凝结热 + 凝固热） | 41.84 | 41.84 |
