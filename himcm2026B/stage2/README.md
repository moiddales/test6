# 阶段二a：公交站冷却效率模型（Requirement 2a）

## 1. 结论

### 效率指标

把阶段一冷柜分析得出的三条原则直接用在公交站上：

| 阶段一的原则 | 在公交站上怎么落实 |
|---|---|
| 只算送达目标的冷量 | 分子只计入**受益人数 × 按热应激等级加权的 UTCI 缓解量** |
| 设备效果随环境空气变化 | 在两个"额定工况"下分别给出效率（相当于冷柜测试标准里的气候等级），给出覆盖所有温湿度的地图（图 3），并用**实测高温日**做全天计算 |
| 效率 = 服务 ÷ 全部资源，先划定边界 | 分母 = **用电 + 用水的隐含能耗**（按城市取值：凤凰城 1.93 kWh/m³，休斯敦用美国平均 0.53 kWh/m³）。漏出去的冷量全部散到街上，没有可以回收的地方 |

> **η = N_ben × R ÷（P_电 + e_水 × V̇_水）**，单位：人·°C·h / kWh

两个额定工况：

- **R-干热：** 42°C / 15%，风速 1.5 m/s，候车 4.17 人
- **R-湿热：** 35°C / 55%，其余条件相同

**设计日：** 凤凰城（PHX）和休斯敦（IAH）机场 2020–2024 年 7 月最热的 10% 的日子，逐小时实测平均：

- 凤凰城：最高 46.4°C、最低 34.2°C，午后露点 8°C
- 休斯敦：最高 37.4°C、最低 27.0°C，露点约 21–24°C

数据和处理方法见 `../data/README.md`。

### 阶段一视角带来的发现

1. **冷量去向（图 7）。** 两种设计日下，蒸发冷却器产生的冷量只有 20–26% 吹到人身上：
   - B：24–26% 到人、40–41% 在路上被热空气稀释、34% 吹向没人的地方；
   - C：20–21% 到人、27–28% 被稀释、52–53% 吹向没人的地方。
2. **零能耗手段（表 6，所有数字都以"开敞候车亭、不开设备"为同一基准）。**
   - **遮阳顶棚**（与站在太阳下相比）每天带来的缓解：干热天 638 人·°C·h，湿热天 208 人·°C·h。干热天接近整天开 B 的效果（672），约为 C（1311）的一半；湿热天约为风扇（242）的 86%。顶棚下的平均辐射温度取气温 + 12°C：实测表明候车亭这类轻质遮阳只比全日晒低约 15°C，见第 4 节参数表。
   - **侧挡风板只适合干热地区。** 挡风板把候车亭里的风减半，这对所有候车人都有影响：
     - 干热天风比皮肤热，挡风让人更舒服，挡风板本身就带来 +57 人·°C·h/天。与设备合用时，B 的总缓解从 672 增到 817，C 从 1311 增到 1539。
     - 湿热天风帮人出汗散热，挡风板本身让人更难受（−87 人·°C·h/天）。与风扇合用时总缓解从 242 降到 200.5，与 B 合用从 312 降到 284，与 C 合用几乎不变。
     - 所以湿热地区的候车亭应保持通风。
3. **用水是真实成本。** 干热设计日 B 用水 1,337 L、C 用水 3,223 L。凤凰城的水要经中亚利桑那调水工程（CAP）提升输送，隐含能耗约为全美平均的 3.6 倍。从不计水改为 2.64 kWh/m³，干热高峰 C 的效率降 20%（35.4 → 28.2）。
4. **按需开关相当于冷柜的夜帘。** 实测干热日风扇在 13–20 时有害。全天开着，效率只有 8.8；只在有益时开（共 9 小时），效率为 26.6。
5. **风扇在 35°C 以上是否有益，文献有分歧（表 7）。**
   - 模型的风扇有害边界：湿度 5% 时从 38.6°C 开始有害；40°C 时水汽压低于 0.74 kPa 才有害。
   - Morris 等 2021 的生物物理模型：年轻人 39°C 以下、老年人 38°C 以下，风扇在任何湿度下都无害。与模型一致。
   - Bröde & Kampmann 2023 的运动实验：35°C 以上，水汽压要高于 2–3 kPa 风才有益。模型比这项实验更偏向"风扇有益"，但受试者在行走，而候车是静坐。
   - Meade 等 2024 的综述：35°C 以上风扇对核心体温没有有意义的降低。按这个最悲观的观点，休斯敦风扇一天只开 10 小时（模型是 16 小时），缓解量从 242 降到 145 人·°C·h，"非常强热应激"剩 31 人·小时（模型是 24）。风扇的 η 仍然最高（59.5），但最热的几个小时要靠蒸发冷却或避暑点。对老年人，应按这个保守口径处理。

6. **额定值怎么读，决定干热天数字的大小（表 9）。** 模型把"最多降 5 / 8°C"读成设备的饱和效率（ε = 0.50 / 0.80），所以空气越干，出风温降越大：凤凰城设计日的 16 个小时里，出风温降都超过额定值（B 7.1–12.1°C，C 11.3–19.4°C）；休斯敦只有 4 个小时超过（B 最大 5.9°C，C 最大 9.5°C）。另一种读法是按字面把出风温降封顶在 5 / 8°C：
   - 干热设计日，B 的缓解量从 672 降到 339，η 从 31.4 降到 16.9；C 的缓解量从 1311 降到 684，η 从 28.8 降到 16.2。"非常强热应激"剩 56.5（B）和 51.7（C）人·小时，原读法是 52.7 和 40.8。
   - 这时 η 最高的是只在早晚开 9 小时的风扇（26.6），但它全天的缓解量只有 59，午后 13–20 时不能开。午后能用的仍然只有蒸发冷却。
   - 湿热设计日几乎不变：B 312 → 301，C 530 → 515。

   "干热天午后用蒸发冷却、风扇关掉"这条建议在两种读法下都成立；字面读法下，蒸发冷却的效果约为一半。

### 效率与效果的分歧（留给第 4 问）

在实测干热日 46.4°C 的高峰，B 和 C 都无法让人脱离"非常强热应激"：

- B 只能把 UTCI 降到 46.1，C 降到 42.9；
- 全天"非常强热应激"的人·小时从 61.7 降到 B 52.7、C 40.8。

所以单靠设备不够，必须加上遮阳和避暑点。湿热日从 34.4 降到 C 0.5、B 12.6、风扇 24.2：效率最高的风扇，安全效果最差。

### 决策规则（表 5）

- **何时用蒸发冷却：** 气温 ≥ 36°C，且干湿球温差高于门槛（36°C 时约 19°C，40°C 时 16°C，42°C 时 15°C，44°C 时 14°C）。其他天气用风扇。
- **干热高峰选 B 还是 C：** 候车 ≤ 6 人时 B 略好或持平（6 人时 B 42.9、C 42.1）；≥ 8 人时 C 明显更好。

## 3. 模型链

```
气候 → M1 湿空气 → M2 设备 → M3 输送（体积 / 定点）→ M4 客流 → M5 UTCI
     → M6 缓解量 × 受益人数 ÷（电 + 水的隐含能耗）
```

**M1 湿空气：** Magnus 饱和水汽压；用二分法解 ASHRAE 绝热饱和方程求湿球温度。

**M2 设备：**
- 蒸发冷却器：
  - 出风温度 T_s = T − ε(T − T_wb)，ε = 额定温降 / D_ref（D_ref = 10°C），得 ε_B = 0.50、ε_C = 0.80；过程焓守恒。
  - 风量取自商用规格表：B 5.0 m³/s，C 7.5 m³/s。
- 风扇：用"体感降 3°C"标定出人体处风速 2.74 m/s。

**M3 输送：**
- 体积模式（冷却整个候车亭）：
  - 区域温度：T_z = φT_s + (1 − φ)T + 人体散热项，φ = Q_s / (Q_s + Q_inf)。
  - 外部空气流入量：Q_inf = √(Q_wind² + Q_buoy²)。
- 定点模式（射流对准人）：T_p = T − θ(T − T_s)，θ = θ0 / (1 + v / u_jet)。

**M4 客流：**
- 利特尔定律：N = λW，平均等待时间 W = (h/2)(1 + CV²)。
- 每台设备最多覆盖的人数 cap = 风量 / 0.8 m³/s。
- 候车人数按泊松分布随机波动，受益人数取期望 E[min(N, cap)]。直接用 min(平均人数, cap) 会高估小设备：人多于 cap 的时候多出来的人吹不到。

**M5 体感：** 用 UTCI。顶棚下平均辐射温度 = 气温 + 12°C；日晒下 = 气温 + 30°C × 太阳高度因子。

**M6 缓解量与效率：**
- 加权剂量 D(U) = ∫₂₆^U w(u) du，权重 w = 1 / 2 / 3 / 4；每人缓解量 R = D(U_before) − D(U_after)。
- 冷量去向分三部分：
  - 吹到人身上：(N_ben / cap) × θ
  - 路上被稀释：(N_ben / cap) × (1 − θ)
  - 吹向没人的地方：1 − N_ben / cap

### 敏感性与稳健性（设计日高峰，实测风速）

- **影响 η 最大的因素：**
  1. 热应激权重：从均等权重到最陡权重，η 相差 7–27 倍；"风扇 vs 蒸发冷却"的排名不变，但干热高峰 B 与 C 本来接近，均等权重下 C 略胜。
  2. 候车人数（干热 C：14.3–64.3）。
  3. 风速和风扇额定参考工况（干热天的风扇）。
  4. 射流占比 θ0（干热 B：22.7–39.5）与 D_ref（干热 B：25.5–37.5）。
- **水的隐含能耗** 0 → 2.64 kWh/m³：干热高峰 B 的效率从 38.5 降到 31.6，C 从 35.4 降到 28.2。
- **蒙特卡洛：** 湿热天风扇 93.2% 排第一；干热天 C 61%、B 39%，风扇 η 全部为负。

### 检验（表 0，14 项全部通过）

- 湿球温度与 Stull 经验式相差 ≤ 0.5°C。
- 能量守恒误差 < 3%。
- 风扇在参考工况的效果为 3.00°C。
- **风扇与真人实验对照：**
  - 40°C / 50%：模型 +1.6，Morris 2019 实测有益；
  - 47°C / 10%：模型 −1.0，Morris 2019 实测有害；
  - 42°C / 50%：模型 +1.4，Ravanelli 2015 实测有益。
- 产品规格表上的耗水量只对应约 2°C 温降。
- 混合模型的两个极限都正确。

另有三项与文献的量级对照（前两项见表 8）：

- **额定值的另一种理解：** 题目表头是"Effect on Shelter"。若把它理解为"最干热时刻、送到人身上的气温降幅"，反推出的饱和效率是 B 0.44、C 0.65，与模型的 0.50、0.80 接近；ASHRAE 手册给出随机填料约 80%。
- **人身上的降温幅度：** 干热高峰时（实测风速 3.7 m/s），模型中 B 让人身上的气温降 3.8°C，C 降 7.1°C，都不到干湿球温差（24°C）的三分之一。户外喷雾在 1–2 m/s 微风下实测气温降 8.2°C、UTCI 降 7.9°C（Ulpiani 等 2019），户外实测降幅最多约为干湿球温差的一半。模型的结果在这个范围之内，并且因为风大而偏低。
- **风扇有害边界：** 与 Morris 2021 的阈值一致（表 7）。

## 6. 交给 2b 的内容

湿空气、设备、UTCI、效率定义、实测设计日（`weather()`）都直接复用。2b 的嵌套检验在相同的实测风速下与 2a 体积模式完全一致。
