# 阶段二a：公交站冷却效率模型（Requirement 2a）

## 1. 结论

### 效率指标

把阶段一冷柜分析得出的三条原则直接用在公交站上：

| 阶段一的原则 | 在公交站上怎么落实 |
|---|---|
| 只算送达目标的冷量 | 分子只计入**受益人数 × 按热应激等级加权的 UTCI 缓解量** |
| 设备效果随环境空气变化 | 在两个"额定工况"下分别给出效率（相当于冷柜测试标准里的气候等级），并给出覆盖所有温湿度的地图（图 3） |
| 效率 = 服务 ÷ 全部资源，先划定边界 | 分母 = **用电 + 用水的隐含能耗**（美国平均 0.48 kWh/m³）。漏出去的冷量全部散到街上，没有可以回收的地方 |

> **η = N_ben × R ÷（P_电 + e_水 × V̇_水）**，单位：人·°C·h / kWh

两个额定工况：

- **R-干热：** 42°C / 15%，风速 1.5 m/s，候车 4.17 人
- **R-湿热：** 35°C / 55%，其余条件相同

### 哪台设备效率最高

| 工况 | 效率最高 | η（人·°C·h/kWh） | 稳健性（3000 组随机参数） |
|---|---|---|---|
| R-湿热 | A 风扇 | A 67.7，B 13.9，C 11.4 | 99.7% 的情况下风扇第一 |
| 极湿 32°C / 75% | A 风扇 | A 87.9，B 10.8，C 8.6 | — |
| R-干热 | B 蒸发冷却器 | B 39.9，C 31.4，A −4.8（风扇让人更热） | B 51%、C 49%；风扇在 86% 的情况下 η < 0 |
| 干热且候车 ≥ 8 人 | C 大型蒸发冷却器 | 8 人时：C 63.9，B 58.9 | — |

### 阶段一视角带来的四个新发现

1. **冷量去向（图 7）：** 蒸发冷却器产生的冷量，只有 B 的 34%、C 的 24% 真正吹到人身上。其余的部分在路上被卷进来的热空气稀释（B 38%、C 24%），部分吹向没人站的地方（B 28%、C 52%）。C 风量大，但人少时大半冷量都打空了。冷柜里只有 13% 的冷量用在商品上，两者是同一个问题。
2. **零能耗手段比设备更强（表 6）：**
   - 遮阳顶棚（与站在太阳下相比）每天带来 801 人·°C·h 的缓解（干热天），比整天开着的 B（685）还多，而且不耗电。
   - 加侧挡风板后，各设备的设计日效率提高 2–6%。
   - 这些相当于冷柜的门和夜帘。
3. **用水是真实成本：** 干热天 B 每小时耗水 85 L，C 每小时 205 L。在水的隐含能耗高的沙漠地区（3 kWh/m³），C 的效率会降低 17%。
4. **按需开关相当于冷柜的夜帘：** 干热天风扇在 13–17 时有害，智能控制把这段关掉后，风扇的效率从 17.7 提高到 26.9。

### 决策规则（表 5）

- **何时用蒸发冷却：** 气温 ≥ 36°C，且干湿球温差高于门槛（36°C 时约 20°C，40°C 时约 16°C，42°C 时约 15°C，44°C 时约 14°C）。其他天气用风扇。
- **干热天选 B 还是 C：** 候车 ≤ 6 人用 B，≥ 8 人用 C。
- **效率与效果的分歧：** 只有 C 能在干热高峰把乘客拉出"非常强热应激"（UTCI 从 B 的 40.0 降到 36.4）。这个分歧留给第 4 问。

## 3. 模型链

```
气候 → M1 湿空气 → M2 设备 → M3 输送（体积 / 定点）→ M4 客流 → M5 UTCI
     → M6 缓解量 × 受益人数 ÷（电 + 水的隐含能耗）
```

**M1 湿空气：** Magnus 饱和水汽压；用二分法解 ASHRAE 绝热饱和方程求湿球温度。

**M2 设备：**
- 蒸发冷却器：
  - 出风温度 T_s = T − ε(T − T_wb)，ε = 额定温降 / D_ref（D_ref = 10°C），得 ε_B = 0.50、ε_C = 0.80；过程焓守恒。
  - 风量取自商用规格表：B 5.0 m³/s，C 7.5 m³/s。
- 风扇：用"体感降 3°C"标定出人体处风速 2.93 m/s。

**M3 输送：**
- 体积模式（冷却整个候车亭）：
  - 区域温度：T_z = φT_s + (1 − φ)T + 人体散热项，φ = Q_s / (Q_s + Q_inf)。
  - 外部空气流入量：Q_inf = √(Q_wind² + Q_buoy²)；浮力项就是冷空气从侧面底部溢出，和冷柜门的渗入是同一种机制。
- 定点模式（射流对准人）：T_p = T − θ(T − T_s)，θ = θ0 / (1 + v / u_jet)。

**M4 客流：**
- 利特尔定律：N = λW，平均等待时间 W = (h/2)(1 + CV²)。
- 每台设备覆盖的人数 = 风量 / 0.8 m³/s。

**M5 体感：** 用 UTCI（pythermalcomfort 计算）。阴影下平均辐射温度 = 气温 + 4°C；日晒下 = 气温 + 30°C × 太阳高度因子。

**M6 缓解量与效率：**
- 加权剂量 D(U) = ∫₂₆^U w(u) du，权重 w = 1 / 2 / 3 / 4；每人缓解量 R = D(U_before) − D(U_after)。
- 冷量去向分三部分：
  - 吹到人身上：(N_ben / cap) × θ
  - 路上被稀释：(N_ben / cap) × (1 − θ)
  - 吹向没人的地方：1 − N_ben / cap

### 敏感性与稳健性

- **影响 η 最大的因素：**
  1. 热应激权重：数值缩放 3.6–9 倍，但两种气候下的排名都不变。
  2. 风扇额定参考工况（干热天的风扇）。
  3. 候车人数。
  4. 射流占比 θ0 与 D_ref。
- **水的隐含能耗**从 0.07 变到 3.0 kWh/m³：干热天 B 的效率从 40.4 降到 33.5，C 从 34.4 降到 27.8。
- **蒙特卡洛：** 湿热天风扇 99.7% 排第一；干热天 B / C 各 51% / 49%；干热天风扇 η < 0 的比例为 86%。

### 检验（表 0，12 项全部通过）

- 湿球温度与 Stull 经验式相差 ≤ 0.5°C。
- 能量守恒误差 < 3%。
- 风扇在参考工况的效果为 3.00°C；RH 20% 时风扇失效温度 41.6°C，生理研究的阈值是老年人约 42°C、年轻人约 45°C。
- 产品规格表上的耗水量只对应约 2°C 温降。
- 混合模型的两个极限（送风量无穷大、送风量为零）都正确。
