# 阶段二a：公交站冷却效率模型（Requirement 2a）

## 1. 结论

### 效率指标

把阶段一冷柜分析得出的三条原则直接用在公交站上：

| 阶段一的原则 | 在公交站上怎么落实 |
|---|---|
| 只算送达目标的冷量 | 分子只计入**受益人数 × 按热应激等级加权的 UTCI 缓解量** |
| 设备效果随环境空气变化 | 在两个"额定工况"下分别给出效率（相当于冷柜测试标准里的气候等级），给出覆盖所有温湿度的地图（图 3），并用**实测高温日**做全天计算 |
| 效率 = 服务 ÷ 全部资源，先划定边界 | 分母 = **用电 + 用水的隐含能耗**（美国平均约 2,000 kWh/百万加仑 ≈ 0.53 kWh/m³）。漏出去的冷量全部散到街上，没有可以回收的地方 |

> **η = N_ben × R ÷（P_电 + e_水 × V̇_水）**，单位：人·°C·h / kWh

两个额定工况：

- **R-干热：** 42°C / 15%，风速 1.5 m/s，候车 4.17 人
- **R-湿热：** 35°C / 55%，其余条件相同

**设计日：** 凤凰城（PHX）和休斯敦（IAH）机场 2020–2024 年 7 月最热的 10% 的日子，逐小时实测平均：

- 凤凰城：最高 46.4°C、最低 34.2°C，午后露点 8°C
- 休斯敦：最高 37.4°C、最低 27.0°C，露点约 21–24°C

数据和处理方法见 `../data/README.md`。

| 干热且候车 ≥ 8 人 | C 大型蒸发冷却器 | 8 人时：C 72.8，B 58.0 | — |

### 阶段一视角带来的发现

1. **冷量去向（图 7）。** 两种设计日下，蒸发冷却器产生的冷量只有 20–28% 吹到人身上：
   - B：27% 到人、45% 在路上被热空气稀释、28% 吹向没人的地方；
   - C：20% 到人、28% 被稀释、52% 吹向没人的地方。

   实测风速比原先假设的大，所以稀释比原先估计的更多。
2. **零能耗手段（表 6）。**
   - 遮阳顶棚（与站在太阳下相比）每天带来的缓解：干热天 896 人·°C·h，超过整天开着的 B（655），约为 C（1203）的四分之三；湿热天 404 人·°C·h，与 C（406）相当，是风扇（190）的两倍多。
   - 加侧挡风板后，各设备的设计日效率提高 7–21%。
3. **用水是真实成本。** 干热设计日 B 用水 1,337 L、C 用水 3,223 L。按加州的水耗能（平均值的 5 倍，2.64 kWh/m³）计，C 的峰值效率降 20%。
4. **按需开关相当于冷柜的夜帘。** 实测干热日风扇在 12–21 时都有害。全天开着，效率是负的（−1.8）；只在有益时开（共 7 小时），效率为 28.3。

### 效率与效果的分歧（留给第 4 问）

在实测干热日 46.4°C 的高峰，B 和 C 都无法让人脱离"非常强热应激"：

- B 只能把 UTCI 降到 42.9，C 降到 38.8；
- 全天"非常强热应激"的人·小时从 55.5 降到 B 47.7、C 33.6。

所以单靠设备不够，必须加上遮阳和避暑点。湿热日 B、C 都能把它降到 0，风扇剩 4.5。

### 决策规则（表 5）

- **何时用蒸发冷却：** 气温 ≥ 36°C，且干湿球温差高于门槛（36°C 时约 20°C，40°C 时 16°C，42°C 时 15°C，44°C 时 14°C）。其他天气用风扇。
- **干热高峰选 B 还是 C：** 候车 ≤ 6 人时两者几乎相同（6 人时 B 55.7、C 54.6）；≥ 8 人时 C 明显更好。

## 3. 模型链

```
气候 → M1 湿空气 → M2 设备 → M3 输送（体积 / 定点）→ M4 客流 → M5 UTCI
     → M6 缓解量 × 受益人数 ÷（电 + 水的隐含能耗）
```

**M1 湿空气：** Magnus 饱和水汽压；用二分法解 ASHRAE 绝热饱和方程求湿球温度。

**M2 设备：**
- 蒸发冷却器：
  - 出风温度 T_s = T − ε(T − T_wb)，ε = 额定温降 / D_ref（D_ref = 10°C），得 ε_B = 0.50、ε_C = 0.80；过程焓守恒。
  - 风量取自商用规格表：B 5.0 m³/s，C 7.5 m³/s。
- 风扇：用"体感降 3°C"标定出人体处风速 2.93 m/s。

**M3 输送：**
- 体积模式（冷却整个候车亭）：
  - 区域温度：T_z = φT_s + (1 − φ)T + 人体散热项，φ = Q_s / (Q_s + Q_inf)。
  - 外部空气流入量：Q_inf = √(Q_wind² + Q_buoy²)。
- 定点模式（射流对准人）：T_p = T − θ(T − T_s)，θ = θ0 / (1 + v / u_jet)。

**M4 客流：**
- 利特尔定律：N = λW，平均等待时间 W = (h/2)(1 + CV²)。
- 每台设备覆盖的人数 = 风量 / 0.8 m³/s。

**M5 体感：** 用 UTCI。阴影下平均辐射温度 = 气温 + 4°C；日晒下 = 气温 + 30°C × 太阳高度因子（日晒混凝土地面实测峰值 75.6°C）。

**M6 缓解量与效率：**
- 加权剂量 D(U) = ∫₂₆^U w(u) du，权重 w = 1 / 2 / 3 / 4；每人缓解量 R = D(U_before) − D(U_after)。
- 冷量去向分三部分：
  - 吹到人身上：(N_ben / cap) × θ
  - 路上被稀释：(N_ben / cap) × (1 − θ)
  - 吹向没人的地方：1 − N_ben / cap

### 敏感性与稳健性（设计日高峰）

- **影响 η 最大的因素：**
  1. 热应激权重：数值缩放 4.6–12 倍；"风扇 vs 蒸发冷却"的排名不变，但干热高峰 B 与 C 本来几乎打平，均等权重下 C 略胜。
  2. 风扇额定参考工况（干热天的风扇）。
  3. 候车人数。
  4. 射流占比 θ0（B：25.2–49.2）与 D_ref（B：28.0–46.9）。
- **水的隐含能耗** 0 → 2.64 kWh/m³：干热高峰 B 的效率从 40.4 降到 33.1，C 从 39.9 降到 31.8。
- **蒙特卡洛：** 湿热天风扇 97.9% 排第一；干热天 C 64%、B 36%，风扇 η 全部为负。

### 检验（表 0，14 项全部通过）

- 湿球温度与 Stull 经验式相差 ≤ 0.5°C。
- 能量守恒误差 < 3%。
- 风扇在参考工况的效果为 3.00°C。
- **风扇与真人实验对照：**
  - 40°C / 50%：模型 +1.38，Morris 2019 实测有益；
  - 47°C / 10%：模型 −1.39，Morris 2019 实测有害；
  - 42°C / 50%：模型 +1.17，Ravanelli 2015 实测有益。
- 产品规格表上的耗水量只对应约 2°C 温降。
- 混合模型的两个极限都正确。
