# 阶段二：公交站冷却效率模型（Requirement 2a）

## 1. 结论

**效率指标**

> η = 受益人数 × 每人的热应激缓解量 ÷ 设备电功率，单位"人·°C·h / kWh"

其中热应激缓解量用 UTCI（通用热气候指数）计算，按热应激等级加权。三台设备的效率排名由气候决定，表格里的"°C/kW"排名（风扇 12，B 4.2，C 3.2）只在温暖、偏湿的天气里成立。

| 气候 | 效率最高 | 结果（η，人·°C·h/kWh） | 稳健性（3000 组随机参数） |
|---|---|---|---|
| 湿热（35°C / 55%） | A 风扇 | A 67.7，B 14.1，C 11.6 | 风扇 99.6% 排第一 |
| 极湿（32°C / 75%） | A 风扇 | A 87.9，B 10.9，C 8.6 | — |
| 干热（42°C / 15%） | B 蒸发冷却器 | B 41.2，C 32.7，A −4.8（风扇让人更热） | B 52%、C 48%；风扇在 87% 的参数组合下 η < 0 |
| 干热，候车人数 ≥ 8 | C 大型蒸发冷却器 | C 的覆盖人数更多 | — |

**决策规则（表 5）**

- 气温 ≥ 38°C、且干湿球温差高于门槛时，用蒸发冷却；门槛随气温升高而降低：38°C 时约 18°C，42°C 时约 15°C，44°C 时约 14°C。其他天气用风扇。
- 干热天里，候车人数 ≤ 6 人时用 B，≥ 8 人时用 C。
- 只有 C 能在干热高峰时段把人从"非常强热应激"（UTCI ≥ 38）拉出来：B 只能到 40.0，C 能到 36.4。这一点留给第 4 问的"效果"分析使用。

## 3. 模型链

```
气候 (T, RH, 风速)
  → M1 湿空气：湿球温度 T_wb、含湿量 W
  → M2 设备：风扇改变风速；蒸发冷却改变温度和湿度
  → M3 输送：开放侧面带走多少冷量（体积模式 / 定点模式）
  → M4 客流：站内平均人数（利特尔定律）
  → M5 体感：UTCI，风扇和冷却器用同一把尺子量
  → M6 有效缓解 × 受益人数 ÷ 功率 = η
```

### M1 湿空气（`psychro.py`）

- 饱和水汽压用 Magnus 式：p_ws = 611.2·exp(17.62T / (243.12 + T)) Pa。
- 含湿量：W = 0.622·p_w / (p − p_w)。
- 湿球温度：用二分法解 ASHRAE 绝热饱和方程。

### M2 设备

**蒸发冷却器**

- 出风温度：T_s = T − ε(T − T_wb)。
- 蒸发过程绝热（焓守恒），由此求出风含湿量 W_s。
- 题表的"最多降 X°C"解释为额定工况下的出风温降：ε = X / D_ref。参考干湿球温差取 D_ref = 10°C，得到 ε_B = 0.50，ε_C = 0.80。
- 风量取自商用产品规格表："18,000 m³/h 对 1.1 kW"、"25,000 m³/h 对 2.2 kW"、"30,000 m³/h 对 3.0 kW"。据此设 B = 5.0 m³/s（1.2 kW），C = 7.5 m³/s（2.5 kW）。
- 制冷量 = ρ·c_p·Q·ΔT；耗水量 = ρ·Q·(W_s − W)。

**风扇**

- 风扇只改变人体处的风速。
- 风速用"额定 3°C"标定：在 30°C / 50%、阴影下，UTCI 恰好降低 3°C 的风速，标定结果为 2.93 m/s。

**风扇失效机制**

- 气温高于皮肤温度（约 35°C）后，吹风会向人体输送热量；UTCI 的人体热平衡模型包含这个机制。
- RH 20% 时，模型给出的风扇失效温度是 41.6°C。生理研究给出的阈值是老年人约 42°C、年轻人约 45°C。公交站乘客包含老年人，所以采用这个偏保守的结果。

### M3 输送：开放侧面的"冰箱门效应"

**体积模式（冷却整个候车亭）**

候车区按充分混合处理：

- 热收支：T_z = φ·T_s + (1 − φ)·T + N·q_p / (ρ·c_p·(Q_s + Q_inf))
- 冷量送达比例：φ = Q_s / (Q_s + Q_inf)
- 外部空气流入量由风压和浮力两部分合成：Q_inf = √(Q_wind² + Q_buoy²)（ASHRAE 渗透模型的平方和合成方式）
  - 风压驱动：Q_wind = C_w·A·v
  - 浮力驱动：Q_buoy = (C_d/3)·W_open·√(g·H_z³·ΔT/T)
- 浮力项是冷空气从敞开侧面底部"溢出"的流量，与冷库门、敞口冷柜渗入计算用的是同一类公式（Gosney–Olama 一族），正好对应第 1 问的冷柜类比。
- 因为 Q_buoy 依赖它自己造成的温差，用不动点迭代求解。

**定点模式（把射流对准人）**

- 吹到人身上的空气 = 冷却风占比 θ + 卷吸进来的环境空气占比 (1 − θ)。
- θ = θ0 / (1 + v_in / u_jet)：风越大，射流被吹偏、稀释得越多。
- 定点模式同时提高人体处风速，这部分降温效果也计入 UTCI。

**数值例子**（图 2，设备 C，42°C / 15%）：出风温降 16.4°C，人所在位置只剩 5–11°C，风越大越少。

### M4 客流

- 利特尔定律：N̄ = λ·W。
- 乘客随机到达时，平均等待时间 W = (h/2)(1 + CV²)，h 为发车间隔，CV 为发车间隔的变异系数。
- 基准：每小时 40 人到站，10 分钟一班，CV = 0.5，得 N̄ = 4.17 人。
- 每台设备能覆盖的人数 = 风量 ÷ 每人所需风量（0.8 m³/s）：A 4 人，B 6.25 人，C 9.4 人。

### M5 体感

UTCI 由 `pythermalcomfort` 计算。

- 输入：气温、平均辐射温度（阴影下取气温 + 4°C）、风速、相对湿度。
- UTCI 要求输入 10 m 高处的风速，人体高度（1.1 m）的风速按对数风廓线乘以 1.47 换算。
- 热应激等级（Bröde et al. 2012）：
  - 26–32：中等
  - 32–38：强
  - 38–46：非常强
  - ≥ 46：极端

### M6 有效缓解与效率

- 加权热应激剂量：D(U) = ∫₂₆^U w(u) du，各等级权重 w = 1 / 2 / 3 / 4。
- 每人缓解量：R = D(U_before) − D(U_after)。
  - 已经舒适（UTCI < 26）时继续降温，不计收益。
  - 把人从危险等级拉出来，收益按权重加倍计算。
- 效率：η = N_ben·R / P。
- 设计日指标：η_day = Σ(N_ben·R) / Σ能耗，另外单独报告耗水量和"非常强热应激人·小时"。

设计日采用代表性高温日：

- 干热（类凤凰城）：最高 43°C、最低 31°C、露点 12°C。对照 NWS 1991–2020 气候常年值，7 月平均最高 41.4°C、最低 29.2°C。
- 湿热（类休斯敦）：最高 36°C、最低 26°C、露点 23°C。对照 7 月平均最高约 35°C，露点在 20°C 中段。
- 两地风速都取 1.5 m/s。
- 客流：早高峰 7–9 时、晚高峰 16–19 时每小时 60 人、10 分钟一班；平峰每小时 25 人、15 分钟一班；19 时后每小时 20 人。

定题后，用所选城市 7 月的实测逐时数据（NOAA ISD 或 Meteostat）替换 `CLIMATES`，客流用当地公交站点数据替换 `ridership()`。

## 5. 结果

### 5.1 单工况对比（表 1，风速 1.5 m/s，4.17 人）

| 工况 | 设备 | 人处气温 / 湿度 | UTCI 前 → 后 | η | 耗水 L/h |
|---|---|---|---|---|---|
| 干热 42°C / 15% | A 风扇 | 42.0 / 15% | 42.6 → 42.7 | −4.8 | 0 |
| | B 定点 | 37.2 / 24% | 42.6 → 38.6 | 41.2 | 85 |
| | B 体积 | 37.8 / 23% | 42.6 → 39.4 | 32.8 | 85 |
| | C 定点 | 33.7 / 34% | 42.6 → 35.1 | 32.7 | 205 |
| | C 体积 | 33.7 / 34% | 42.6 → 36.4 | 28.1 | 205 |
| 湿热 35°C / 55% | A 风扇 | 35.0 / 55% | 38.0 → 36.0 | 67.7 | 0 |
| | B 定点 | 33.2 / 63% | 38.0 → 36.0 | 14.1 | 33 |
| | C 定点 | 31.8 / 70% | 38.0 → 34.6 | 11.6 | 80 |

从表 1 读出的几点：

1. **蒸发冷却的降温幅度由气候决定。** 干热天 B、C 在人所在处的气温降 5–8°C；湿热天只降 2–3°C，而且人处湿度升到 63–70%。
2. **定点模式的 η 比体积模式高 16% 到约 5 倍。** 两者送到人处的气温相近，差别来自射流带来的风速；越湿热，风速这部分占比越大。
3. **冷量送达比例：** 定点模式下吹到人身上的风只有 47–51% 是冷却风，体积模式下 42–52% 的冷量留在候车区，其余被风和浮力带走。
4. **耗水量：** 干热天 B 每小时耗水 85 L。产品规格表上写的 15–20 L/h，按能量守恒只对应约 2°C 的温降，所以规格表数字只适用于温和工况。

### 5.2 设计日（表 2，6:00–22:00，定点模式）

| 气候 | 设备 | 全天电耗 kWh | 全天耗水 L | η_day（始终开启 / 智能控制） | "非常强热应激"人·小时：前 → 后 |
|---|---|---|---|---|---|
| 干热 | A | 4.0 | 0 | 17.7 / 26.9 | 52.3 → 45.3 |
| | B | 19.2 | 1193 | 35.7 / 36.4 | 52.3 → 28.1 |
| | C | 40.0 | 2874 | 28.2 / 28.7 | 52.3 → 0 |
| 湿热 | A | 4.0 | 0 | 63.5 / 66.3 | 18.0 → 2.2 |
| | B | 19.2 | 500 | 14.3 / 15.6 | 18.0 → 0 |
| | C | 40.0 | 1203 | 11.4 / 12.4 | 18.0 → 0 |

- **智能控制规则：** 仅当 UTCI ≥ 32、设备确实有益、且站内有人时开机。站内有人的概率按泊松分布计算：1 − e^(−N̄)。
- **控制效果：**
  - 干热天风扇在午后会帮倒忙，智能控制把这些时段关掉，η 从 17.7 提高到 26.9。
  - 其余设备省电 2–14%：本设计日客流较大，站内几乎一直有人。客流越小，按需开关省电越多（η 与人数成正比，见表 3）。

### 5.3 敏感性与稳健性（图 5、图 6，表 3、表 4）

**影响 η 最大的因素：**

1. 候车人数：所有设备都受影响，η 与覆盖人数成正比。
2. 风扇额定参考工况：只影响干热天的风扇。参考温度越高，标定出的风速越大，在 43°C 时给人的热负荷也越大。
3. 射流占比 θ0 和 D_ref：影响蒸发冷却。
4. 阴影辐射温度：影响湿热天的风扇。

**权重方案：** 从 1-1-1-1 换到 1-3-9-27，η 的数值变化约 3.6–9 倍，但两种气候下的排名都不变。

**蒙特卡洛**（3000 组参数，所有参数在敏感性范围内均匀抽样，权重方案随机）：

- 湿热天风扇 99.6% 排第一。
- 干热天 B、C 各约一半（52% / 48%）。
- 干热天风扇在 87% 的参数组合下 η 为负。

## 7. 交接给阶段三（2b 火车站）

可以直接复用的部分：

- M1 湿空气、M2 设备、M5 UTCI、M6 效率定义；
- 体积模式的混合方程（2b 的出发点）；
- 定点模式的射流公式。

需要修改的部分：

| 改动 | 原因 |
|---|---|
| 静态混合 → 动态热平衡 C·dT/dt | 半封闭空间会蓄热 |
| 换气量由开口面积和封闭度决定 | 公交站是封闭度约为 0 的特例 |
| 人流按列车到站脉冲变化 | 车到站时人群骤增骤减 |
| 加入压缩式空调（COP 约 3）和除湿 | 半封闭空间做空调开始可行 |
| 只冷却下部 2 m 的人员活动区 | 量化热分层的节能效果 |
